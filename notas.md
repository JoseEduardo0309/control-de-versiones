# Notas del proyecto

## Control de versiones

Conceptos clave aprendidos:

- **git init**: Inicializa un repositorio
- **git branch**: Crea y lista ramas
- **git checkout**: Cambia de rama
- **git add**: Prepara cambios para commit
- **git commit**: Guarda cambios con un mensaje
- **git push**: Sube cambios al repositorio remoto

## Flujo de trabajo

1. Crear una rama nueva desde `main`
2. Realizar cambios en la rama
3. Hacer commits con mensajes descriptivos
4. Fusionar la rama con `main` cuando esté lista
